# Moon Letter

A minimal, browser-local image message app. English and Unicode text are hidden in generated PNG pixels and recovered from the original image. No database, API keys, or external services.

Publish from the `main` branch and repository root in GitHub Settings → Pages.

Send the original PNG as a file. Resizing, screenshots, and lossy compression destroy the message. This is steganography, not password-protected encryption; anyone with this app and the image can decode it.
